F3X Creator Store Browser

A home page for the F3X model-browser project. The goal is to search Roblox Creator Store models by name—such as “SpongeBob statue”—instead of returning avatar catalog items.

API status: not connected yet.
This is a static website. GitHub Pages cannot run the server-side search proxy, so model search won't work until an API endpoint is deployed and connected.

Next steps

  1. Publish this site with GitHub Pages.
  2. Deploy the Creator Store search API to a runtime that supports server-side requests.
  3. Connect the Delta model browser to that API and test real model results.
